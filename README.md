# base_of_data
laba_1.sql - Запросы с условием
Фильтрация данных с помощью WHERE, операторов LIKE, SIMILAR TO, ESCAPE, работы с датами (EXTRACT), проверки на NULL, а также сортировки и конкатенации строк.

laba_2.sql - Строковые и числовые функции
Использование строковых функций (CONCAT, SUBSTRING, LOWER, LENGTH) и математических функций (ROUND, TRUNC, ABS, SIGN, SQRT) для преобразования и вычисления данных.

laba_3.sql - Функции для работы с датами
Форматирование дат (TO_CHAR), вычисление стажа и отработанных месяцев (AGE, EXTRACT, DATE_TRUNC), работа с юлианским календарем и интервалами.

laba_4.sql - Функции агрегации
Группировка данных (GROUP BY), фильтрация групп (HAVING), вычисление средних, минимальных и максимальных значений (AVG, MIN, MAX, COUNT, SUM), а также объединение строк через STRING_AGG.

laba_5.sql - Соединение таблиц
Объединение данных из нескольких таблиц с помощью JOIN, LEFT JOIN, RIGHT JOIN и USING. Отработка соединений в FROM и в WHERE.

laba_6.sql - Подзапросы
Использование вложенных запросов (коррелированных и некоррелированных), операторов IN, сравнение с агрегатными функциями и многостолбцовые подзапросы.

laba_7.sql - Рекурсивные запросы (CTE)
Построение иерархических запросов с помощью WITH RECURSIVE для работы со структурой подчинения сотрудников (поиск руководителей, подсчет подчиненных, построение цепочек).

laba_8.sql - Создание таблиц и манипуляция данными (DDL/DML)
Проектирование схемы базы данных для фитнес-клуба (таблицы trainers, halls, bookings). Создание таблиц с ограничениями (PRIMARY KEY, FOREIGN KEY, UNIQUE, NOT NULL, CHECK), изменение структуры (ALTER TABLE), наполнение данными (INSERT, UPDATE, DELETE), а также демонстрация работы ограничений БД (вызов ошибок при нарушении целостности).
